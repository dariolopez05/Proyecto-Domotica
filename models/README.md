# Modelos (`models/`)

Carpeta para guardar artefactos de modelos y métricas.

Sugerencia:
- Guarda aquí **métricas** (`metrics.json`) y **metadatos** del experimento.
- Si los modelos (`.pkl`, `.keras`, etc.) son grandes, considera ignorarlos en git o moverlos a `artifacts/` / almacenamiento externo.
